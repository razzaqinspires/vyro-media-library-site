# VYRO MEDIA Library 2.0.0

This release adds a browser-local experimental production workspace while preserving the website as a thin presentation layer. It does not vendor AI, TTS, FFmpeg, scheduler, or Instagram publishing code into the website root.

## Included
- Local demo identity and IndexedDB project drafts.
- Project-level selection/access toggles for public library assets.
- Local media upload storage.
- Canvas photo editor with PNG export.
- Experimental vertical video editor with WebM export.
- Optional API bridges for intake, script generation, voice, and final rendering.

## Not included
- Google OAuth or user accounts.
- Cloud draft persistence or cross-device synchronization.
- Multi-user asset sharing.
- Instagram publishing or scheduling controls.
- Browser-side MP4 master rendering.
